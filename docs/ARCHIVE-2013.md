# Arquivo 2013 — preservação e catalogação

Este diretório documental registra os materiais históricos que deram origem à promessa retomada pelo projeto em 2026.

## Material já identificado

- fotografias de 2013;
- publicações em redes sociais;
- vídeos publicados no YouTube;
- registros profissionais relacionados às cozinhas;
- registros comerciais que possam ser divulgados.

## Registro mínimo

Para cada item:

| Campo | Conteúdo |
|---|---|
| ID | identificador único |
| data | data conhecida ou aproximada |
| origem | Facebook, YouTube, arquivo pessoal etc. |
| autor | autoria conhecida |
| local | local conhecido |
| tipo | foto, vídeo, documento etc. |
| contexto | relação com a história |
| direitos | situação de uso/publicação |
| arquivo | nome ou referência do arquivo |

## Primeiro marco

Uma das imagens fornecidas para o projeto está datada de **16 de outubro de 2013** e registra uma etapa da atividade profissional daquele período.

## Vídeos

Os links fornecidos pelo autor devem ser mantidos como referências históricas até que sejam catalogados com título, data, origem e contexto.

## Regra de preservação

Não editar o arquivo original para publicação. Manter:

1. original;
2. cópia de preservação;
3. versão editada para publicação;
4. metadados e contexto.

O arquivo histórico é diferente dos dados da expedição de 2026.
