# Arquitetura

## Camadas

1. **Captura** — câmera 360°, celular e GPS.
2. **Live** — transmissão e posição pública.
3. **Dados** — JSON versionado no GitHub.
4. **Portal** — GitHub Pages.
5. **360°** — publicação posterior no Google Street View.
6. **Automação** — VUA, GitHub e Bluesky.

O portal não depende de o vídeo 360° estar ao vivo no Google Street View. A transmissão ao vivo e o Street View são fluxos complementares.
